# RoadToSmartBaking Marketing Studio concepts

Corrected stakeholder concept for the internal no-code backoffice used by the Moretti Marketing team.

The product model is:

```text
Structured editor and approved templates
                 +
Live RoadToSmartBaking mobile simulator
                 +
Draft → Request review → Approve → Publish
```

## Recommended presentation order

1. `01-content-library-and-templates.png` — one library for restaurants, events, stories, programs, collections and banners.
2. `02-restaurant-studio.png` — structured restaurant editor with immediate mobile detail preview.
3. `03-event-studio.png` — event creation, targeting, placement and mobile preview.
4. `04-explore-composer.png` — constrained arrangement of approved Explore modules with instant simulation.
5. `05-review-and-publish.png` — before/after comparison, validation, device/locale previews, approval and scheduling.

This is a constrained no-code content studio, not a public website builder, restaurant portal or unrestricted drag-and-drop canvas. Approved templates and mobile components protect brand consistency, accessibility and implementation feasibility.

The earlier `stakeholder-dashboard` images should be treated as an initial administrative exploration. This folder represents the clarified primary backoffice experience.
